# Project Documentation

This folder contains supporting documentation for the Enbridge Pipeline Flow & Inventory Monitoring project.

The documentation explains the data sources, dataset structure, field definitions, and operational KPIs used throughout the analysis.

## Documentation Files

### data_sources.md
Documents the sources of the pipeline operational datasets, collection methods, access links, and any relevant data limitations.

### data_dictionary.md
Describes the dataset fields, data types, meanings, units of measurement, and their relevance to pipeline operations.

### kpi_definitions.md
Documents the operational KPIs used in the project, including their definitions, calculation methods, units, and business relevance.

## Purpose

To ensure that the project is transparent, understandable, reproducible, and supported by clearly documented data and KPI definitions.
