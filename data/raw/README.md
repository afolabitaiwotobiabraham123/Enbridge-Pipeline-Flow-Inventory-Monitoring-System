# Raw Data

This folder stores the original datasets collected for the Enbridge Pipeline Flow & Inventory Monitoring project.

The datasets in this folder will remain in their original, unmodified format.

Data will be examined, assessed, and prepared using Python and Jupyter Notebook before being saved in the `data/processed/` folder.

**Purpose:**
- Store original pipeline operational datasets.
- Preserve source data for reference.
- Maintain a clear separation between raw and processed data.
