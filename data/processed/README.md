# Processed Data

This folder stores datasets that have undergone data cleaning and preparation for the Enbridge Pipeline Flow & Inventory Monitoring project.

The datasets will be prepared using Python, Jupyter Notebook, and Pandas.

**Purpose:**
- Store cleaned and prepared pipeline operational datasets.
- Maintain consistent data formats.
- Prepare datasets for MySQL storage and SQL analysis.
- Support pipeline flow, inventory, and operational KPI analysis.

Only validated and prepared datasets should be stored here.
