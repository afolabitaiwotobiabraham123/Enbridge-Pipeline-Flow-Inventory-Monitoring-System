# Python Analysis

This folder contains the Jupyter Notebooks used for data acquisition, exploratory data analysis, data quality assessment, and data cleaning and preparation.

Python, Jupyter Notebook, and Pandas will be used to prepare pipeline operational data for further analysis in MySQL and Power BI.

## Notebooks

### 01_data_acquisition.ipynb
Collects and imports pipeline operational datasets from the selected data sources.

### 02_exploratory_data_analysis.ipynb
Explores the dataset to understand its structure, variables, distributions, and operational patterns.

### 03_data_quality_assessment.ipynb
Assesses the dataset for missing values, duplicates, invalid records, inconsistencies, and potential outliers.

### 04_data_cleaning_and_preparation.ipynb
Cleans and prepares the dataset, applies documented corrections, and produces validated data for MySQL analysis.

## Tools

- Python
- Jupyter Notebook
- Pandas

## Workflow

Data Acquisition → Exploratory Data Analysis → Data Quality Assessment → Data Cleaning and Preparation
