# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Enbridge Pipeline Flow & Inventory Monitoring project.

The dashboard will transform the results of the pipeline flow and inventory analysis into interactive visual reports to support operational monitoring and decision-making.

## Dashboard Objectives

- Monitor incoming and outgoing pipeline flows.
- Track inventory movements over time, where data is available.
- Highlight differences between inflow and outflow.
- Monitor key pipeline operational performance indicators.
- Identify periods requiring further operational investigation.

## Folder Structure

### dashboard/
Stores the Power BI dashboard file (`.pbix`).

### screenshots/
Stores screenshots of the completed dashboard and its visualizations.

## Tool

- Microsoft Power BI
